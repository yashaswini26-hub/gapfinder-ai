# GapFinder AI — Retrieval-Augmented Generation (RAG) Pipeline

## 1. Pipeline Overview

The GapFinder AI RAG pipeline transforms raw, unstructured student materials (syllabi, course notes, slide exports, and past exam questions) into a high-precision, citation-grounded knowledge base. Every question generated by the diagnostic engine and every explanation delivered by the topic assistant is explicitly linked to source document chunks.

```
+------------------+     +-------------------+     +--------------------+
|  Raw PDF / TXT   | --> | Server Extraction | --> | Semantic Chunking  |
| (Uploaded Files) |     | (pdf-parse / Text)|     | (600t, 100t overlap)
+------------------+     +-------------------+     +--------------------+
                                                             |
                                                             v
+------------------+     +-------------------+     +--------------------+
| pgvector Storage | <-- | 768d Vector Embed | <-- | Metadata Tracking  |
|  (HNSW Cosine)   |     | text-embedding-004|     | (Page, Sec, DocID) |
+------------------+     +-------------------+     +--------------------+
         |
         v
+------------------+     +-------------------+     +--------------------+
| Authenticated    | --> | Cosine Similarity | --> | Grounded Diagnosis |
| Vector Retrieval |     | (Threshold >=0.45)|     |  & Citations UI    |
+------------------+     +-------------------+     +--------------------+
```

---

## 2. Text Extraction & Sanitization

Located in `src/lib/ai/ingestion.ts`:
- **PDF Extraction**: Server-side extraction utilizing `pdf-parse` to read binary streams and extract clean textual content.
- **Page Boundary Preservation**: Page markers (`--- PAGE X ---`) are identified and assigned to respective chunks.
- **Scanned PDF Detection**: If total extracted characters across multiple pages fall below a minimum density threshold (e.g., $<50$ characters per page), the document is safely flagged as `failed` with status:
  `"Scanned or image-only PDF detected. Please upload a document with selectable, machine-readable text."`
  This prevents silent failures or generating hallucinated empty embeddings.
- **Normalization**: Extraction artifacts, erratic linebreaks, zero-width characters, and excessive whitespace are normalized.

---

## 3. Chunking Strategy

Located in `src/lib/ai/chunking.ts`:
- **Target Size**: ~600 tokens (~2,400 characters) per chunk.
- **Sliding Overlap**: ~100 tokens (~400 characters) overlap between sequential chunks to preserve semantic context across chunk boundaries.
- **Structural Boundary Detection**:
  - Markdown headings (`#`, `##`, `###`)
  - Uppercase chapter/module headers (e.g., `MODULE 1: DATA EXPLORATION`, `UNIT 2: SUPERVISED LEARNING`)
  - Double newline paragraph breaks
- **Metadata Enriched per Chunk**:
  ```typescript
  export interface DocumentChunk {
    id: string;
    document_id: string;
    user_id: string;
    chunk_index: number;
    content: string;
    page_number?: number;
    section_title?: string;
    token_count?: number;
    embedding?: number[];
    created_at: string;
  }
  ```

---

## 4. Embedding Generation

Located in `src/lib/ai/embeddings.ts`:
- **Model**: `text-embedding-004` (official Google Gen AI embedding model).
- **Vector Dimensions**: Exactly **768 dimensions**.
- **Batch Processing**: Embedded in batches of 16 chunks with bounded retry logic to prevent API throttling and timeouts on large notes.
- **Deterministic Vectors**: Normalized vectors stored directly into PostgreSQL `vector(768)` columns.

---

## 5. Storage & Vector Indexing

Located in `supabase/migrations/20261026000000_gapfinder_schema.sql`:
- **Extension**: `pgvector` enabled in Supabase PostgreSQL.
- **Index Type**: Hierarchical Navigable Small World (`HNSW`) with cosine distance operator (`vector_cosine_ops`):
  ```sql
  CREATE INDEX idx_document_chunks_embedding 
  ON document_chunks 
  USING hnsw (embedding vector_cosine_ops);
  ```
- **Tenant Isolation**: Row Level Security (`RLS`) ensures students can only search and access chunks from their own uploaded documents.

---

## 6. Retrieval & Filtering

Located in `src/lib/ai/retrieval.ts`:
- **Security Pre-Filter**: Every vector query passes `filter_user_id` and `filter_subject_id`.
- **Stored Procedure (`match_document_chunks`)**:
  ```sql
  CREATE OR REPLACE FUNCTION match_document_chunks(
    query_embedding vector(768),
    match_threshold float,
    match_count int,
    filter_user_id uuid,
    filter_subject_id uuid
  )
  RETURNS TABLE (
    id uuid,
    document_id uuid,
    chunk_index int,
    content text,
    page_number int,
    section_title text,
    similarity float
  )
  ```
- **Relevance Gating**:
  - Minimum similarity threshold: **0.45** (configurable).
  - Top-K: **4** most relevant non-redundant chunks per diagnostic question or assistant query.
- **Fallback Rule**: If no chunks meet the 0.45 threshold, the system explicitly returns:
  `"Available course material does not contain sufficient information to support this topic."`
  The system refuses to silently fabricate answers from external model pretraining.

---

## 7. Citation Generation & Validation

- **Structured Citations**: Every citation contains the source document filename, exact page number, and section header:
  `[Lecture 03 - Feature Engineering, Page 7, Section "One-Hot Encoding"]`
- **Validation**: Generated questions must pass Zod schema validation requiring that all `source_references` match the chunk IDs retrieved for that specific query.
- **Clickable UI Drawer**: Clicking any citation pill opens `CitationDrawer.tsx`, presenting the exact text excerpt from the student's study material.

---

## 8. Pipeline Limitations & Mitigations

| Limitation | Impact | Mitigation in GapFinder AI |
| :--- | :--- | :--- |
| **Scanned Hand-written PDFs** | No extractable text stream | Explicit failure status explaining OCR requirement |
| **Complex Multi-column Tables** | Text order may be flattened | Chunk boundary splitting on structural headings |
| **Very Small Files (<100 tokens)** | Insufficient chunk volume | Minimum token check with single-chunk fallback |
| **Synonym Mismatch** | Pure keyword search misses synonyms | Semantic vector search via 768d embeddings |
